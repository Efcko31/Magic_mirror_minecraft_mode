# Magic Mirror Mod (Fabric)

Простой и удобный мод для Minecraft на базе Fabric, добавляющий магические зеркала для быстрой и комфортной телепортации.

---

## Особенности мода

* **Два типа зеркал:**
    * **Simple Magic Mirror (Обычное зеркало):** Телепортирует игрока на его точку спавна (кровать или мировой спавн) с предварительной подгрузкой чанков.
    * **Super Magic Mirror (Супер-зеркало):** Позволяет перемещаться между измерениями и на любые расстояния. Использует систему предзагрузки чанков и уникальный Mixin, который полностью скрывает экраны загрузки мира.
* **Плавная анимация:** Во время использования зеркала персонаж подносит его к лицу (анимация подзорной трубы).
* **Атмосферные звуки:** Кастомные звуковые эффекты зарядки и телепортации.
* **Баланс опыта:** Использование супер-зеркала требует опыт и имеет задержку повторного использования (cooldown).

---

## Рецепты крафта

### Simple Magic Mirror (Обычное зеркало)

* Стекло x4
* Золотой слиток x2
* Железный слиток x2
* Эндер-жемчуг x1

```
[ Стекло ] [ Железный слиток ] [ Стекло ]
[ Золотой слиток  ] [   Эндер-жемчуг    ] [ Золотой слиток  ]
[ Стекло ] [ Железный слиток ] [ Стекло ]
```

### Super Magic Mirror (Супер-зеркало)

* Стекло x4
* Незеритовый слиток x2
* Алмаз слиток x2
* Цветок хоруса x1

Схема крафта (3x3):

```
[ Стекло ] [ Незеритовый слиток ] [ Стекло ]
[ Алмаз  ] [   Цветок хоруса    ] [ Алмаз  ]
[ Стекло ] [ Незеритовый слиток ] [ Стекло ]
```

## Установка

1. Установите Fabric Loader для вашей версии Minecraft.
2. Скачайте и поместите в папку `mods` библиотеку Fabric API.
3. Поместите `.jar` файл Magic Mirror Mod в папку `mods`.
4. Запустите игру.

---

## Требования

* Minecraft с установленным Fabric Loader
* Java 21 или выше
* Fabric API
